# Portfolio Writeup

## Project Title

Automated Azure Cost Visibility Dashboard with Terraform, GitHub Actions, and Azure Static Web Apps

## Summary

Built a cloud cost visibility dashboard that helps teams understand Azure spending, monitor budget usage, and identify top cost drivers. The solution uses Terraform for infrastructure deployment, GitHub Actions for CI/CD, Azure Static Web Apps for hosting, React for the dashboard UI, and Azure Functions for the backend API.

## Business Problem

Small businesses and cloud teams often struggle to understand where Azure costs are coming from. Technical billing categories can be difficult for non-technical stakeholders to interpret, which can lead to budget surprises.

## Solution

This project presents Azure cost data in a simple business-friendly dashboard. It shows current spend, budget usage, weekly trends, and top cost drivers. The project is deployed using infrastructure as code and CI/CD to demonstrate real-world cloud automation.
